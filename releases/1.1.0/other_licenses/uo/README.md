# Units of Measurement Ontology (UO)

`units.csv` carries, for each unit, the UO identifier (such as UO:0000016) and the UO name of the unit (such as millimeter). They are taken from UO, release 2026-10-12, http://purl.obolibrary.org/obo/uo.owl, which is licensed CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Credit: Unit Ontology, Gkoutos G. V., Schofield P. N., Hoehndorf R. et al., https://github.com/bio-ontology-research-group/unit-ontology. No other UO wording is carried. The rest of the release is CC0 1.0.
